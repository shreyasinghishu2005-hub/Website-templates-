# Website Templates

A collection of three standalone, responsive website templates built with HTML and CSS. Each project is organized in its own folder and can be previewed locally in a web browser.

## Templates

### 1. Sure Success Canada
**Folder:** `Client 2/`

A professional website for a medical exam preparation institute serving International Medical Graduates in Canada.

- Preparation information for MCCQE1, NAC-OSCE, MCCQE2 and USMLE
- In-person and online learning information
- Editorial-style typography and a calm navy, green and gold visual palette
- Responsive navigation and page sections

### 2. Cube Systems Portfolio
**Folder:** `Cube System/`

A futuristic portfolio/agency-style website with a dark interface.

- Neon cyan, magenta and lime accent palette
- Grid-inspired background and interactive visual details
- Portfolio-focused layout and navigation
- Responsive presentation

### 3. ICS Coaching Jaipur
**Folder:** `ICS Coaching/`

A coaching institute website focused on competitive exam preparation in Jaipur.

- Course and institute information
- SSC, Railway, Delhi Police, Army, Bank and LDC exam categories
- Reviews, features and contact sections
- Separate CSS stylesheet with responsive styling
- Uses Google Fonts and Remix Icon CDN resources

## Getting Started

No build tools or package installation are required for the included templates.

1. Download or clone this repository.
2. Open the folder for the template you want to preview.
3. Open its `index.html` file in a modern browser.

For a local development server, you can use the VS Code **Live Server** extension, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` and navigate to the relevant template folder.

## Notes

- These are independent template projects; each folder can be used separately.
- Some fonts and icon assets are loaded from external CDNs, so an internet connection may be needed for those resources.
- Replace the sample business content, contact details, images and links with your own before publishing.
- Review all claims, ratings, statistics and contact information in the sample pages for accuracy before using them in a live website.
