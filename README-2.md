## 🌟 Overview

**Website Templates Collection** brings together three standalone
website projects, each designed for a different use case. The collection
includes a medical exam-preparation website, a futuristic portfolio
experience, and a coaching-centre website.

Explore the source, customize the content and styling, and use the
templates as a starting point for your own web projects.

## 🚀 Getting Started

No build tools or package installation are required for the basic
preview.

1.  Download or clone this repository.
2.  Open the project folder you want to explore.
3.  Open its `index.html` file in a modern browser.

### Run with VS Code

For a local development preview, open the repository in Visual Studio
Code and launch `index.html` using the **Live Server** extension.

## 🛠️ Customization

-   **Content:** Edit headings, descriptions, links and section text in
    the relevant `index.html`.
-   **Styles:** Update CSS variables, colors, spacing and typography in
    the page styles. The ICS Coaching project uses a separate
    `index.css` file.
-   **Assets:** Add your images, logos and other assets to the relevant
    project folder, then update their paths in the HTML.
-   **Links and contact details:** Replace demo or existing contact
    information with details you are authorized to publish.

## 💡 Suggested Workflow

1.  Choose the template closest to your project.
2.  Review its HTML structure and existing styles.
3.  Replace the sample branding and content.
4.  Test the layout at desktop and mobile widths.
5.  Check navigation, buttons, forms and external links before
    publishing.
